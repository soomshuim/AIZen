## 회신 요약 (문항별)

### B-0. 두 봇 중 택1 — **미답변**

발송본에서 B-0는 괄호 섹션 앞 산문 문단이었고, 니키는 두 봇 문항 세트에 모두 상세 답변함. 명시적 선택 없음.

### [믹스패널 리포트 봇]

**B1-1. 리포트 항목 / "사용 현황"의 정체**
- 목적: 고객사들이 믹스패널을 잘 쓰는지 **사용량 확인**.
- 구 플로우: 믹스패널 콘솔(첨부1·2) → 계산기 시트에 복사 → 정제값을 스프레드시트에 붙여넣기. **이 콘솔은 API 없음(니키 실측)**.
- 현 플로우: 믹스패널 본사가 만들어준 **파트너 대시보드**(첨부3)에서 사용량 체크 → **주차별 인사이트 요약을 상단에 수기 기입**. 본사 제공 데이터인데 **MCP·AI 기능 꺼져 있어 일일이 체크**. 그래프는 있으나 고객사별로 보기 힘듦.

**B1-2. 고객사 수 / 접근 방식**
- 고객사 수: 명시 답변 없음. 첨부3 기준 티어 1~3으로 수십 곳 관찰(DreamUs·wrtn·Homeplus·LG전자·SK Group·Kolon Mall·LY·RXC·Finda·INFLAB·Scatter Lab 등).
- 접근: **개인 계정 초대**로 진행 중. 서비스 계정(사람 아닌 프로그램용 계정)은 "본사로부터 받을 수 있을지도" — 미확정.

**B1-3. 전달**: 리포트는 **링크와 함께 슬랙으로**. 노션 아카이브도 하고 있으나 우선순위 아님.

**B1-4. 현재 비용**: 매주 담당자 1인 **약 30분**. 클로드코드 헤드리스 브라우저 화면 조회로 하면 ~15분(클로드 실행 시간 제외) — **팀이 이미 클로드코드 반자동화를 시도해본 상태**.

### [일일 업무 다이제스트 봇]

**B2-1. 원천**: 슬랙 채널 7곳 — **전부 비공개**. 컨설팅팀 PA / 세일즈팀 / 마케팅팀 / (이름 미표시 1곳) / 공지 / 컨설팅팀 MMP / 컨설팅팀 CRM.
- **정정(2026-08-31 젠)**: 채널명이 "비공개 채널"로만 보인 것은 니키 누락이 아니라 **젠 계정 권한 때문** — 젠 계정이 해당 비공개 채널 미가입이라 슬랙이 이름을 가림. 채널 실명 확보는 니키 재질문 사안이 아니라 **접근 권한 해결에 종속**.

**B2-2. 이상형**
- 동기: 크지 않은 조직인데 서로 뭐 하는지 모름. 팀원 번아웃으로 "찾아볼 에너지"가 없음.
- 목표 형태: **폴의 길드장뉴스** 느낌 — "껌 씹으면서 대충 읽을 가벼운 뉴스지만 있을 내용은 다 있는". (참조 자료는 이번 첨부에 미포함 — 첨부 3장은 전부 믹스패널 건)
- 반면교사: 레플릿(Replit)로 팀별 탭 뉴스레터 시도 → 협업이 팀 경계를 넘나들어 **내용 구분이 명쾌하게 안 됨**, 자동화 한계로 중단.

**B2-3. 발송**: "슬랙이나 매주 솔루션즈 노션에 뉴스처럼" — **주기 = 매주 확정(2026-08-31 젠)**. 내용은 솔루션즈 전원 열람.

**B2-4. 정보 취사**: 없어도 되는 것 = 세금계산서 발행 요청·finance 단순 행정 요청·계약서 요청. **빠지면 안 되는 것 1가지는 미답변**.

## 봇 확정 (2026-08-31 젠 결정)

**확정: 다이제스트 봇.** 기준은 범용성 + 구현 난이도 — 두 축 모두 다이제스트 봇 우위.

- 범용성: 슬랙 지정 채널 읽기 → LLM 요약 → 발송 파이프라인이 모니카 케이스(퀘스트 초안)와 뼈대 공유. 길드 복제 가능 패턴. 수혜 범위도 솔루션즈 전원.
- 구현 난이도: 접근이 열리면 요약·편집 프롬프트가 핵심(코드 단순). 믹스패널 봇은 API 없는 콘솔의 헤드리스 브라우저 자동화라 난이도·취약성 모두 높음.
- 수용한 리스크: 비공개 채널 접근 승인(주체 미배정, 폴·진배 9/8까지 통신 불가)이 런칭일 블로커로 잔존. 완화 = 샘플 데이터로 파이프라인 선구축, 접근 개통 시 연결.
- 믹스패널 봇은 탈락이 아니라 **차순위 보류** — V1 이후 재상정 후보(니키 실측·첨부 요약은 이 문서에 보존).
