## A. 현재 AI 사용 실태 (리터러시·토큰 베이스라인)

**A1.** 요즘 업무에서 AI를 어떻게 쓰고 계세요? 쓰는 도구(챗GPT·클로드 등)와 유료 구독 여부가 궁금해요.

> [의도] 리터러시 베이스라인 + 토큰 동기 사전 신호. 유료 구독을 이미 쓰면 ⓒ 가능성 낮고, 무료만 쓰면 ⓒ 탐침 필요.

**A2.** 슬랙 봇이나 자동화(재피어·MCP·API 연동 같은 것)를 직접 만들거나 연결해 본 적 있으세요?

> [의도] ⓐ 판별 — 연동 경험 유무. "MCP"라는 단어에 대한 반응 자체가 B1의 사전 신호.

**A3.** 퀘스트 입력을 편하게 만들려고 뭔가 직접 시도해 본 적 있나요? 해봤다면 어디서 막혔는지, 안 해봤다면 이유가 뭐였는지 궁금해요.

> [의도] **ⓐ(방법 모름) vs ⓑ(귀찮음) 직접 판별의 핵심 질문.** "방법을 몰라서" vs "알아볼 시간/에너지가 없어서" vs "해봤는데 막혀서"로 갈린다.

## B. 퀘스트봇 MCP (안 만들어도 될 일 판별)

**B1.** 혹시 퀘스트봇에 MCP가 이미 만들어져 있다는 건 알고 계셨어요?

> [의도] 인지 확인. **안내하기 전에 먼저 물어야** 응답이 오염되지 않는다. 싱크 가설 = "인지 못했을 가능성이 가장 큼".

**B2.** (B1 안내 후) MCP 연결 방법을 정리해서 드리면 직접 세팅해서 쓰실 것 같으세요, 아니면 세팅까지 다 된 걸 받는 쪽이 좋으세요?

> [의도] 자가 해결 가능성. "직접 세팅"이면 MCP 안내·가이드 제공으로 종결 가능(봇 제작 불필요). "받는 쪽"이면 그 이유가 ⓐ인지 ⓑ인지 이어서 판별.

**B3.** 이게 개인 AI 계정(본인 구독·토큰)으로 도는 것과 길드 공용으로 도는 것 — 어느 쪽을 기대하셨어요? 개인 비용이면 안 쓸 것 같다 싶은 지점이 있나요?

> [의도] ⓒ 판별. 부담 없게 "기대"를 먼저 묻고 비용 수용선을 이어 묻는다.

## C. 채널·데이터 확정

**~~C1·C2~~.** ~~채널 실명 목록 + 비공개 표시~~ — **젠 기확보(2026-09-02), 모니카에게 묻지 않는다.** 후속 용도는 유지: 확보된 목록에서 비공개 채널 여부를 확인해 접근 방식(봇 초대 + 회사 인티그레이션 허용 선행)과 고객사 채널 열람 민감도를 판정한다.

**C3.** 하루에 하신 일이 그 채널들 대화에 얼마나 남아 있어요? 하루치 일감 5~6건 중에, 채널 대화만 보고 알아낼 수 있는 게 몇 건쯤일까요?

> [의도] **우려 ② 초안 품질** — 팀이 슬랙에 말을 많이 하는 스타일이 아니면 채널 대화→퀘스트 산출 자체가 성립 안 한다. 성립률이 낮으면 소스 재설계(퀘스트봇 MCP로 전일 입력 이력 참조 등) 필요.

## D. 아웃풋 채널 (사용 품질 관찰)

**D1.** 초안을 DM 말고 저희도 같이 볼 수 있는 채널로 받는 것도 괜찮으세요? 실제로 쓰는 모습을 보면서 개선하려는 취지예요.

> [의도] **우려 ①** — DM이 아웃풋이면 품질 파악을 모니카 피드백에만 의존. 거부감 있으면 강제하지 않고(DM 유지) 피드백 루프를 별도 설계.

## 판별 → 방향 매트릭스

| 인터뷰 결과 | 방향 |
|---|---|
| MCP 몰랐음 + 안내·가이드면 직접 세팅 의향 | **MCP 안내/세팅 가이드 제공으로 종결 후보** — "안 만들어도 될 일". P0 봇 제작 불필요 가능성 |
| 방법 모름(ⓐ) + 직접 세팅은 부담 | P0 확정안(`v1-p0-monica.md`)대로 봇 제작 — 지원 가치 있음. 단 ⓐ가 길드에 규모 있게 존재하는지는 별도 확인 |
| 알지만 귀찮음(ⓑ) | 임팩트 낮음 — 다음 젠·도 재싱크에서 우선순위 재론 |
| 길드 토큰 희망(ⓒ)이 주 동기 | 지원 형태 재설계(토큰 제공 vs 봇 제작) — 재싱크 안건 |
| C3 산출 성립률 낮음 | 소스 재설계 — 채널 수집 단독으로는 P0 성립 곤란, 퀘스트봇 MCP 이력 결합 검토 |
