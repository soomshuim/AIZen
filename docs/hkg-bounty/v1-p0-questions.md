## A. 모니카 (개인) — 퀘스트 자동 입력 에이전트

1. 퀘스트는 지금 **어디에, 어떤 형식으로** 입력하고 있나요?
   (퀘스트봇 명령어 / 노션 / 폼 등 — 실제 입력 화면 캡처 1장이면 제일 좋아요)
2. **잘 쓴 퀘스트 예시 2~3개**를 그대로 복사해서 보여주실 수 있나요?
   (에이전트가 따라 쓸 목표 샘플이에요)
3. 퀘스트 내용의 재료가 되는 곳에 순위를 매긴다면? —
   슬랙 공개 채널 / DM / 이메일 / 캘린더 중 실제로 어디에 단서가 제일 많나요?
   공개 채널이라면 구체적으로 어떤 채널들인가요?
4. DM은 개인 대화라 접근에 제약이 있을 수 있어요.
   **공개 채널 + 이메일 + 캘린더만으로 시작**해도 쓸만할까요?
5. "시간 입력만 제가" — 이상적인 하루 흐름을 그려주세요.
   (예: 매일 오후 5시에 에이전트가 퀘스트 초안을 DM으로 보내주면, 시간만 적어 확정한다?)
6. 퀘스트를 하루/주에 몇 건 정도 입력하나요? 한 건 쓰는 데 지금 얼마나 걸리나요?
7. 전부는 아니어도 **"이것 하나만 돼도 편하다" 싶은 최소 기능** 하나만 꼽는다면?

## B. 니키 (솔루션즈) — 봇 2건

**B-0.** 두 봇 중 **팀에 먼저 필요한 것 하나**를 고른다면 어느 쪽인가요? 이유도 한 줄로!
(첫 버전은 하나에 집중하고, 나머지는 그다음에 이어가려 해요)

### B-1. 고객사 믹스패널 사용 현황 리포트 봇

1. 리포트에 꼭 들어가야 할 항목은 뭔가요? — "사용 현황"이 구체적으로 무엇인지
   (이벤트 수집량? 대시보드/리포트 조회 활동? 특정 지표?)
   지금 수동으로 확인하는 화면 캡처 1장이면 제일 좋아요.
2. 대상 고객사는 몇 곳이고, 믹스패널 프로젝트 접근은 지금 어떻게 하고 있나요?
   (계정 초대 / 서비스 계정 / API 키 — 아는 만큼만)
3. 리포트는 **누구에게, 어느 채널로, 얼마나 자주** 오면 좋은가요?
4. 지금 이 확인 작업을 사람이 하면 한 번에 얼마나 걸리나요?

### B-2. 솔루션즈 일일 업무 다이제스트 봇

1. "일일 업무 진행 상황"의 원천은 어디인가요?
   — 모아야 할 슬랙 채널들(또는 노션·시트 등)을 알려주세요.
2. 다이제스트가 어떤 모양이면 매일 읽게 될까요?
   머릿속 이상형을 3~5줄로 흉내 내주시면 그대로 목표 삼을게요.
3. **언제, 어느 채널로** 발송되면 좋은가요? 수신 대상은 솔루션즈 전원인가요?
4. 빠지면 안 되는 정보 1가지 / 없어도 되는 정보 1가지를 꼽는다면?
