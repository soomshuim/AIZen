## 회신 원문 (2026-08-31, 문항별 매핑)

**Q1. 입력 형식** — 퀘스트봇 명령어와 입력 플로우로 입력 중. (화면 캡처는 미제공)

**Q2. 잘 쓴 퀘스트 예시 3건 (원문 그대로)**

```
!퀘스트 삼쩜삼 GEO Agent 계약 관련 내부 커뮤니케이션 및 진행사항 F/U ~20260729 1h
!퀘스트 프로젝트 채널 권한 변경 요청 및 설정 조정 ~20260727 0.5h
!퀘스트 고객사 요청업무 대응: bepicked Summary Text 정리 및 전달 ~20260727 4h
```

→ 실측 문법: `!퀘스트 <업무 내용> ~<날짜 YYYYMMDD> <소요시간 h>` (소수점 시간 허용: 0.5h)

**Q3. 재료 순위** — 슬랙: 프로젝트 채널, DM / 구글: 이메일, 캘린더

**Q4. DM 제외 폴백** — 공개 채널 전체가 아니라 **본인 지정 채널**(MFL 프로젝트 채널, 고객사 소통 채널)로 지정해서 진행 희망. → DM 제외는 수용, 단 채널은 지정제.

**Q5. 이상적 하루 흐름** — **매일 오전 9시**, D-1(전날)까지 진행된 업무에 대한 퀘스트 초안을 DM으로 수신 → 문구 수정(필요시) + 시간 기입 → 확정.

**Q6. 볼륨·현재 비용** — 하루 평균 5~6건. 건당 최소 5~10분(과거 이력 뒤져서 아이템 정리 + 시간 확인). 진짜 페인 = 매일 입력이 밀리고, 밀리면 월 마감까지 미입력.

**Q7. 최소 기능(P0 시드)** — "특정 프로젝트에 대해 특정일, 퀘스트 업무 내용"만이라도 정리된 초안.

## P0 확정안 (초안 — 젠 승인 대기)

**이름(가칭)**: 모니카 퀘스트 초안 에이전트

**코어 루프 (V1)**
1. 매일 오전 9시 실행.
2. 모니카 지정 슬랙 채널에서 D-1 활동을 수집.
3. 모니카 관련 업무를 추출해 `!퀘스트 <내용> ~<날짜> __h` 포맷 초안 생성 — **시간은 빈칸**(모니카 기입 영역).
4. 슬랙 DM으로 초안 목록 발송.
5. 모니카가 문구 수정 + 시간 기입 후 **본인이 퀘스트봇에 직접 입력**.

**V1 포함**: 슬랙 지정 채널 수집 / 일 1회 오전 9시 스케줄 / `!퀘스트` 포맷 초안 / DM 발송.

**V1 제외 (근거와 함께)**
- **DM 소스** — 모니카가 Q4에서 제외 수용.
- **이메일·캘린더 소스** — 구글 인티그레이션 허용 미확인(확인 주체 미배정, 폴·진배 9/8까지 통신 불가). 모니카 1순위도 슬랙이므로 V1은 슬랙만으로 성립. 후속 버전 후보.
- **퀘스트봇 자동 입력(에이전트가 대신 입력)** — 모니카 최소 기능 답변이 "초안 정리까지". 확정·입력은 본인 유지가 안전(오입력 리스크 차단).
- **소요시간 추정** — 모니카가 "시간만 제가" 명시.

**성공 기준**: 하루 5~6건 중 초안이 실제 업무를 커버하고, 건당 작성 비용 5~10분 → 1~2분(수정+시간 기입)으로 단축. 월 마감 미입력 백로그 소멸.

## 후속 질문 (~~발송 대기~~ → **발송 불요 종결, 2026-09-02** — 채널 목록 젠 기확보)

목적: 에이전트가 읽을 **지정 채널 목록 확정** + 공개/비공개 여부(접근 방식 갈림). → 젠이 목록을 이미 확보해 발송하지 않는다. 아래 초안은 이력 보존용.

발송 초안:

```
모니카, 자세한 답변 감사합니다! 딱 두 가지만 더 여쭤볼게요.

지정 채널로 진행하는 쪽으로 잡았는데, 에이전트가 읽을 채널을 확정하고 싶어요.

1. MFL 프로젝트 채널 / 고객사 소통 채널의 실제 채널명을 목록으로 알려주실 수 있나요? (#채널명 형태면 제일 좋습니다)
2. 그중 비공개 채널이 있으면 어떤 것인지 표시 부탁드려요. (접근 방식이 달라서요)

이것만 확정되면 첫 버전 제작 들어갑니다 :raised_hands:
```

## 리스크 (모니카 케이스 한정)

- **지정 채널이 비공개일 가능성** — 고객사 소통 채널은 비공개일 확률 높음. 비공개면 봇/에이전트 계정의 채널 초대 + 회사 슬랙 인티그레이션 허용이 선행 조건 → 미배정 리스크(허용 확인 주체)와 직결.
- **고객사 소통 채널 열람 민감도** — 고객사 대화를 에이전트가 읽는 것에 대한 회사 정책 확인 필요(같은 미배정 리스크의 하위 항목).
